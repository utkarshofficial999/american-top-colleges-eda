# American Top Colleges Exploratory Data Analysis (EDA)

An exploratory data analysis of the **Forbes America's Top Colleges** dataset using Python, Pandas, and NumPy.

## 📂 Project Structure
- `AmericasTopColleges.csv`: Dataset containing rankings and statistics for 650 US colleges.
- `Forbes_Americas_Practice_Questions.ipynb`: Jupyter notebook containing comprehensive warm-up exercises and business analysis questions.
- `README.md`: Project overview and documentation.

## 📊 Key Highlights & Findings
- **Data Cleaning & Handling**: Imputed missing categorical attributes with mode and numeric values with median; standardized column headers for dot-notation access.
- **Top Ranked Institutions**: Harvard, Stanford, Yale, MIT, and Princeton hold the top 5 spots.
- **Public vs. Private**: The dataset comprises 400 Private colleges and 250 Public universities.
- **Geographic Concentration**: Covers 51 states and territories, led by New York (68 colleges), California (56), and Pennsylvania (40).
- **Financial Aid & Alumni Outcomes**: Evaluated Average Grant Aid (led by Yale and Stanford at >$50k/yr) and categorized Alumni Salary into distinct tiers (Low, Medium, High).
